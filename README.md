the Kerch Bridge road span collapsing after a Ukrainian strike, Iran saying
tankers were hit by mines near the Strait of Hormuz as USS Theodore Roosevelt
joins two carriers in the region, Xi, Trump and Putin set to meet in Shenzhen
on Thursday, five EU states planning a Rwanda return hub for rejected asylum
seekers, and the ULA Vulcan rocket failing ten minutes after its Sunday launch,
losing 40 Amazon satellites. The artwork is original illustration; all text is
rendered in code with real fonts, and every fact follows the day's reporting.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `out/entry.png`. Running it twice produces
byte-identical output. No network access is needed.
